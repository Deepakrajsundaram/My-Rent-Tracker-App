# D's Rent Tracker V1.1

iPhone-first dark-mode rent tracker.

## Run
Open `index.html` in a browser.

## Included
- `index.html` — app
- `ds_rent_tracker_logo.png` — D's Rent Tracker logo

## Data safety
All app data is stored locally in browser `localStorage` under `rentTrackerV1Data`.
V1.1 preserves the same storage key and data structure used by V1.
Future versions must migrate/preserve existing stored data rather than resetting it.

## V1.1 features
- 6 houses
- Editable house name, tenant and rent
- Current-month dashboard
- Full/partial payment recording
- Exact payment date
- Persistent payment history
- History screen with month navigation
- Per-house payment dates and amounts
- Monthly expected/collected/outstanding totals
- Share current-month status
- Local storage
